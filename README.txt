楊羽涵｜個人作品集網站

使用方式：
1. 解壓縮 ZIP，保留 index.html、styles.css、script.js 與 assets 資料夾結構。
2. 直接開啟 index.html 可在電腦預覽。
3. 上傳整個資料夾內容到靜態網站服務（例如 GitHub Pages、Netlify、Cloudflare Pages）。
4. 如更新照片，替換 assets/avatar.png；作品圖片放在 assets/works/ 並維持檔名或修改 index.html、script.js 對應路徑。

網站內容：
- 首頁、關於我、作品集、聯絡資訊
- 五項作品依 PDF 順序呈現
- 作品分類篩選與作品圖片燈箱瀏覽
- 影片作品連結：Google Drive、YouTube
- IG 與 Email 聯絡
- 響應式設計、手機導覽、像素風格、粉色/淺黃色調

作品連結：
作品一《在都市裡尋找海的方法》：Google Drive
作品二《Whiplash》Dance Cover：YouTube
作品五 Blue Hours：專案頁

注意：使用 Google Fonts 時，需有網路才能載入字體。所有圖片素材均置於 assets 資料夾。
